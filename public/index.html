Poznámky:
Převodní kurzy: 1 USD = 23 CZK, 1 USD = 0,92 EUR, 1 EUR = 25 CZK.
U AWS/GCP/Azure jsou ceny zaokrouhleny, zahrnují compute + storage.
GCP IaaS Start (e2-micro) má sdílené jádro — výkonově není srovnatelný s dedikovaným 1 vCPU.
App Engine ceny předpokládají 730 h/měs běhu (neškálují se do nuly).
Azure App Service jsou uvedeny za Windows ceny (Linux je levnější).
Ceny jsou orientační, vždy ověřte v oficiální kalkulačce providera.

Metodika

Business Cloud (T-Cloud) – IaaS Resource Pool

Cena za celou architekturu jako sdílený pool (ne per-VM). Celkem = Σ CPU GHz × sazba + Σ RAM GB × sazba + Σ disk GB × sazba tieru + 2× disk × záloha + public IP. CPU se účtuje za celková GHz zaokrouhlená nahoru.

Závazek CPU (Kč/GHz/měs) RAM (Kč/GB/měs) Super Fast Fast Standard Basic

Remote backup 0,68 Kč/GB/měs na 2× celkový disk; public IP 108 Kč/měs při přítomnosti opnsense firewallu.

AWS / GCP / Azure – IaaS matching

Pro každé VM se vybere nejlevnější instance splňující vCPU i RAM: vCPU = max(1, ceil(cpuGHz / 2,6)), RAM = max(1, ceil(ramGB)); cena = USD/hod × 730 + diskGB × storage sazba.

PaaS varianty (Elastic Beanstalk / App Engine / App Service / T-Cloud PaaS)

VM se namapuje na nejmenší PaaS tier (1/2, 2/4, 4/8, 8/16 vCPU/RAM); T-Cloud PaaS se násobí využitím (výchozí 40 %).
